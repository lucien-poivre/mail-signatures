# mail-signatures

Images of Lucien Poivre's e-mail signatures, served by GitHub Pages at
`https://lucien-poivre.github.io/mail-signatures/v1/<file>.png`.

Files under a version folder never change: sent mails point at them. A new design goes in a new folder (`v2/`).
Source: the `mail` skill of the `leon` plugin (`plugins/leon/skills/mail/signatures/`).
